# Online School

Онлайн-школа для занятий математикой и физикой.

## Локальный запуск

Требуются Docker и Docker Compose v2.

```sh
make local-up
```

Приложение будет доступно на <http://localhost:3000>, API — на
<http://localhost:8080>. При первом запуске `build/.env.local` создается из
примера автоматически.

Создание первой учетной записи модератора:

```sh
make local-bootstrap
```

Остановка приложения без удаления данных:

```sh
make local-down
```

Все локальные команды можно посмотреть через `make help`.

## Production

1. Создать файл настроек:

   ```sh
   make prod-init
   ```

2. Заполнить `build/.env.prod`: указать домен, надежные пароли, ссылки на
   Telegram и WhatsApp. Значение `DATABASE_URL` должно содержать тот же пароль,
   что и `POSTGRES_PASSWORD`.
3. Направить DNS домена на публичный IP сервера и открыть входящие TCP-порты
   80/443 и UDP-порт 443.
4. Проверить и развернуть приложение:

   ```sh
   make prod-config
   make prod-deploy
   ```

5. Один раз создать начальную учетную запись модератора:

   ```sh
   make prod-bootstrap
   ```

Caddy автоматически получает и обновляет TLS-сертификат. `make prod-down`
останавливает контейнеры, но не удаляет базу данных и другие постоянные тома.
